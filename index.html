    Good questions

    Clear answers, before you dive in.

    ALLEY Cloud is designed around tools you control. Here are the key things to know about the concept and what a live service needs behind the scenes.

    Ready to get started? →
    Is NANO AI live yet?

    This downloaded website is a front-end demo with sample replies. Making NANO AI live requires a server-side AI endpoint, securely managed provider credentials, usage limits, and error handling. Never place a production API key in browser JavaScript.

    Can ALLEY Cloud really SSH into my Raspberry Pi?

    Not from this static page. A real implementation needs an authenticated backend or private tunnel, careful SSH key handling, device authorization, and access controls. The terminal shown here is simulated and never connects to a device.

    Will the website be hosted on my Raspberry Pi?

    That is the intended use case: your Pi can serve your own site, while the service helps with setup and domain routing. Public hosting from home depends on uptime, bandwidth, router/ISP restrictions, TLS, and a secure networking design.

    Do I get a domain with a paid plan?

    Free is demo-only. Plus proposes one IP/domain endpoint; Pro and Ultra propose one custom domain. Domain provisioning and DNS/IP routing need to be connected to a real backend before launch.

    How many Linux servers are included?

    Every paid plan—Plus, Pro, Ultra, and Business—includes one Linux server intended for SSH access. Free is demo-only and does not provision a server. In this prototype the server is a planned feature: a secure provisioning and SSH gateway backend must be built before connections are live.

    How does Business pricing work?

    Business starts at $5/month. Choose optional AI capacity, website projects, Pi connections, storage, team tools, priority support, or dedicated deployment in the plan customizer. Configurations can range from $5 to $100+ per month; plans above $100 require a final custom quote. The on-page total is only a demo estimate.

    Which plans include Proxy and VPN?

    Proxy and VPN are available as standalone Plus, Pro, Ultra, or Business feature subscriptions. Their capacity, regions, throughput, and usage rules must be defined before launch. They are planned features and are not active services yet.

    Are these prices and limits final?

    No. They are illustrative feature-subscription prices and limits. Validate NANO AI provider costs, domain costs, support needs, storage requirements, proxy/VPN infrastructure, server resources, and the real limits of the Raspberry Pi connection service before launch.

    Deploy the secure promo-code backend

    This single HTML file contains your entire public website and the source templates for the Supabase backend. The backend source is included here so you can copy it into Supabase without downloading a ZIP.

    Important: GitHub Pages only runs the browser website. It cannot securely run database migrations or Edge Functions. You must copy the SQL into Supabase SQL Editor and deploy the two Edge Functions separately. Never paste a service-role key into this HTML file. The initial promo code below is a placeholder, not a working code.

    Before deployment

    1. Set SUPABASE_URL near the bottom of this HTML to the exact URL shown by Supabase → Connect. It must look like https://YOUR_PROJECT_REF.supabase.co. The publishable key is already filled in.
    2. Create your owner account privately in Supabase Authentication → Users using khalidelanid2@gmail.com. Copy its immutable User UID.
    3. Open Supabase → SQL Editor, copy the migration source below, replace CHANGE_WITH_PRIVATE_6_DIGIT_CODE-p with a private six-digit code in the format 123456-p, and run it. Do not put the real code in public GitHub.
    4. Install the Supabase CLI, run supabase login and supabase link --project-ref YOUR_PROJECT_REF.
    5. Set the owner secrets using your actual Auth UID: supabase secrets set ALLEY_OWNER_USER_ID="YOUR_OWNER_AUTH_USER_UUID" ALLEY_OWNER_EMAIL="khalidelanid2@gmail.com".
    6. Deploy both functions: supabase functions deploy redeem-promo and supabase functions deploy get-current-promo-code.

    What the promo system does: each valid code is single-use globally. A successful redemption atomically grants ALLEY Prime/all-feature promo entitlements and rotates to a new random code. Only the approved owner Auth UID plus owner email can view the current code in the dashboard. Admin access is not granted to ordinary redeemers.

    Initial code safety: the migration text intentionally contains a placeholder. Choose a fresh code privately and replace the placeholder before running SQL. Do not share the real code or expose it in GitHub.
